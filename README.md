# TinyFeed — TinyPhone 📱

โทรศัพท์จำลองสำหรับโรลเพลย์ใน **SillyTavern** — มีหน้าโฮมและแอปในตัว **5 แอป** ให้ตัวละคร/NPC มีชีวิตนอกบทสนทนาหลัก เสริมบรรยากาศ worldbuilding และ (ถ้าเปิด) ทักหาเราเองได้แม้ไม่ได้เปิดแอปอยู่

> เปิดจากเมนู extensions (ไอคอนไม้กายสิทธิ์ข้างกล่องพิมพ์) → เข้าหน้าโฮม → เลือกแอป

---

## 📲 แอปในเครื่อง

### 📱 TinyFeed — ฟีดโซเชียล + ข่าวสาร
- โพสต์เอง หรือกดให้ AI โพสต์ในนามตัวละครหลัก/NPC · ไลค์ · แชร์ · คอมเมนต์ · หน้ารายละเอียดโพสต์
- **ปุ่ม "ให้ NPC คอมเมนต์"** บนโพสต์ที่ยังไม่มีคอมเมนต์ · **ลบคอมเมนต์** ที่ไม่ต้องการได้
- **AI ตอบคอมเมนต์** (ตอบทันที / กดปุ่มขอ) · **คอมเมนต์ NPC ติดโพสต์ใหม่** (ไม่มี / AI เลือกจำนวน / กำหนดเอง)
- **สร้างโพสต์อัตโนมัติ** ทุก N ข้อความ · **แท็บข่าวสาร** AI แต่งข่าวเสริมโลก (auto แยกได้)

### 💬 TinyConnect — แชตสไตล์ไลน์
- แชตเดี่ยวกับตัวละครหลัก/NPC · **แชตกลุ่ม** (ตั้งชื่อ + เลือกสมาชิก + **ตั้งรูปกลุ่มได้ทั้งตอนสร้างและแก้ทีหลัง**)
- **แยกข้อความหลายบรรทัดเป็นหลายบับเบิล** (เปิด/ปิดได้) · **ลบบับเบิลแชต** ได้
- ช่องพิมพ์หลายบรรทัด: เดสก์ท็อป **Enter = ส่ง / Shift+Enter = บรรทัดใหม่** · มือถือ **Enter = บรรทัดใหม่ ส่งด้วยปุ่ม ✈**
- **กลุ่มคุยกันเอง** — ปุ่ม "ให้กลุ่มคุยกันต่อ" + โหมดอัตโนมัติ (ดูหัวข้อทักเชิงรุก)

### 🎥 TinyStream — ไลฟ์สตรีม + คอมเมนต์สด
- เริ่ม/จบไลฟ์ (AI ตั้งหัวข้อ + สุ่มผู้ชม) · สตรีมเมอร์เลือกได้ (ตัวละครหลัก/เราเอง)
- คอมเมนต์สดผู้ชม AI 3 โหมด (กดโหลด / ไหลอัตโนมัติ / ไหลตอนเราคอมเมนต์) · พิมพ์คอมเมนต์เองได้

### 📅 TinyMemo — กำหนดการ + โน้ต/ความจำ *(ใหม่)*
- **แท็บกำหนดการ** — ไทม์ไลน์อีเวนต์ที่กำลังจะเกิด · ติ๊กเสร็จได้ / AI ขีดฆ่าอันที่ผ่านไปแล้วให้ตอนสแกน
- **แท็บโน้ต/ความจำ** — บันทึกเหตุการณ์สำคัญที่เกิดใน RP + ข้อเท็จจริงที่อยากให้จำ (AI จับให้ หรือเขียนเอง)
- ปุ่ม **"สแกน"** ครั้งเดียวได้ทั้งสองแท็บ (หากำหนดการใหม่ + ปิดอันเก่า + จดความจำ) · เพิ่มเอง/ลบได้
- ใช้เป็น **แหล่งความจำให้ตัวละคร RP** ได้ (ดูหัวข้อการเชื่อมกับ RP)

### 🗣️ TinyForum — เว็บบอร์ด/กระทู้ *(ใหม่)*
- ตั้งกระทู้เอง (หัวข้อ + เนื้อหา + **ห้อง**) หรือกด "ให้ชาวเน็ตตั้งกระทู้" ให้ AI สร้างจากเนื้อเรื่อง
- แท็บ **ล่าสุด / มาแรง** · คอมเมนต์จำนวนมาก + **ตอบกลับซ้อน 1 ชั้น** + ปุ่ม **"โหลดคอมเมนต์เพิ่ม"** (กดได้เรื่อยๆ)
- ไลค์/ลบ กระทู้·คอมเมนต์·รีพลาย ได้ · **ระบบห้อง/หมวด** เพิ่ม-แก้เองได้ในตั้งค่า (AI เลือกจากรายการ)

## 📢 ทักเชิงรุก + แจ้งเตือน *(ใหม่)*

### ตัวละครทักหาเราเอง (Proactive)
ตัวจับเวลาเบื้องหลังจะให้ตัวละครหลัก/NPC (สุ่มจากแชท ST ปัจจุบัน) **ทักเข้าห้องแชต TinyConnect เอง** เป็นระยะ — คุมด้วย:
- เว้นระยะขั้นต่ำ (นาที) + โอกาสต่อรอบ (%) + **ช่วงเงียบ (quiet hours)** ไม่ทัก
- สไตล์เสริม (ผสมได้): **ทักตอนเงียบนาน (idle)** · **ตามช่วงเวลาจริง** (เช้า/บ่าย/ดึก) · **ทักผ่านโพสต์ฟีดแทน DM**
- **กลุ่มคุยกันเองอัตโนมัติ** เป็นระยะ

> ⚠️ ทำงานเฉพาะตอน **เปิดแท็บ SillyTavern ค้างไว้** (ย่อ/พับได้ แต่ห้ามปิดแท็บ/เครื่อง sleep) และมีแชตที่มีตัวละครเปิดอยู่ · ไม่ต้องเปิดห้องแชตของใครค้างไว้ ระบบสุ่มเลือกให้เอง · ยิง AI เป็นระยะ = เปลือง token

### แจ้งเตือน 3 ชั้น
- **แบนเนอร์** เลื่อนลงบนจอ (กดแล้วเข้าห้อง/แอปที่เกี่ยว) + จุดแดงนับเลขบนปุ่มเมนู + สั่น
- **ลิ้นชักในโทรศัพท์** — ไอคอน 🔔 บน topbar เก็บประวัติ 30 รายการล่าสุด (แตะเข้าแอป, ล้างได้) · เก็บถาวรข้าม reload
- **แจ้งเตือน OS/desktop จริง** (เปิด/ปิดได้, default ปิด) — ยิงผ่าน Service Worker รองรับมือถือ · มีปุ่ม **"ทดสอบแจ้งเตือน OS"** บอกสาเหตุถ้าติด
  - ต้องเปิด ST ผ่าน **HTTPS หรือ http://localhost** (เปิดผ่าน IP/HTTP ธรรมดา เบราว์เซอร์จะบล็อก)
  - ⚠️ ข้อความจะโผล่บน lock screen/แถบ OS แบบเห็นได้ — **ระวังเนื้อหา 18+**

### จำหน้าจอล่าสุด
เปิดแอปใหม่/หลัง reload จะกลับไปหน้า/ห้องเดิม (ไม่เด้งกลับโฮมทุกครั้ง)

## 🔗 การเชื่อมกับโรลเพลย์

- **แทรกเข้าประวัติแชทหลัก** (`setExtensionPrompt` ตำแหน่ง IN_CHAT, ตั้ง depth ได้) — เลือกได้ 5 แบบ: ไม่แทรก / เฉพาะโพสต์ / เฉพาะข่าว / โพสต์+คอมเมนต์ / โพสต์+คอมเมนต์+ข่าว · เพิ่ม checkbox **แทรกแชต TinyConnect / ไลฟ์ TinyStream / กำหนดการ+โน้ต TinyMemo / กระทู้ TinyForum** → ตัวละครอ้างอิงได้ เช่น *"เห็นที่โพสต์แล้วนะ" / "อย่าลืมนัดพรุ่งนี้"*
- **เชื่อมเนื้อหาข้ามแอป** — เป็น **checkbox รายแหล่ง** เลือกได้ว่าให้แอปอื่นเห็นอะไรบ้าง (โพสต์ / คอมเมนต์ / ข่าว / แชต / ไลฟ์ / กำหนดการ / กระทู้) · แชต TinyConnect ปิดไว้ default เพื่อความเป็นส่วนตัว
- **จำนวนล่าสุดที่แทรก** = นับ "ต่อแอป" (กี่โพสต์/ข่าว/ข้อความต่อคน/คอมเมนต์) · **depth** = ตำแหน่งความลึกในประวัติแชท ไม่ใช่จำนวน

## 🤖 ระบบ Generation

- ใช้ `generateQuietPrompt()` — สร้างเนื้อหาโดยไม่ปนบทสนทนาหลัก · **เลือกโมเดล/API แยกได้** ผ่าน Connection Manager (มี fallback)
- โหมดโมเดลแยกแนบบริบทให้เอง: ตัวละครหลัก · Persona · World Info (ครบทุกตำแหน่ง) · บทสนทนาล่าสุด
- **ตัดส่วน reasoning/thinking อัตโนมัติ** · ตั้ง token + คำสั่งเสริมได้แยกทุกแอป

## 🧩 การตั้งค่าขั้นสูง — แก้ Prompt เอง *(ใหม่)*

เผื่อ AI ไม่ทำตามรูปแบบ (เช่นได้คำบรรยายแทนโพสต์) แก้ prompt ของตัวสร้างเนื้อหาได้เอง — ครอบคลุม: โพสต์ฟีด · คอมเมนต์ติดโพสต์ · AI ตอบคอมเมนต์ · ข่าว · ตั้งกระทู้ · คอมเมนต์กระทู้

**กติกา:**
- ต้องคง **marker** ที่ระบุไว้เสมอ (เช่น `POST:` / `COMMENT:` / `TITLE:`) — เพราะระบบใช้ marker นี้แยกผลลัพธ์ · ถ้าลบออก → ขอบแดง + ไม่บันทึก
- กด **"คืนค่าเริ่มต้น"** เพื่อรีเซ็ตเทมเพลตนั้น
- `{{...}}` = ช่องที่ระบบเติมข้อมูลให้อัตโนมัติตอนสร้าง (อย่าพิมพ์ทับ ให้วางไว้ในตำแหน่งที่ต้องการ)

### {{ }} แต่ละอันแทนอะไร

| Token | แทนที่ด้วย |
|---|---|
| `{{roster}}` | รายชื่อผู้โพสต์/คอมเมนต์ที่ให้ AI เลือก (ตัวละครหลัก + NPC ประจำ) |
| `{{extra}}` | คำสั่งเสริมที่ผู้ใช้พิมพ์ในช่อง "คำสั่งเสริม" ของแอปนั้น |
| `{{history}}` | โพสต์/หัวข้อข่าวล่าสุดที่มีอยู่แล้ว (กันเขียนซ้ำ) |
| `{{context}}` | เนื้อหาจากแอปอื่น (เมื่อเปิด "เชื่อมเนื้อหาข้ามแอป") |
| `{{postText}}` | ข้อความของโพสต์ที่กำลังคอมเมนต์ |
| `{{author}}` | ชื่อเจ้าของโพสต์ |
| `{{count}}` | คำสั่งจำนวนคอมเมนต์ที่ให้เขียน (ตามโหมดคอมเมนต์ติดโพสต์) |
| `{{thread}}` | คอมเมนต์ล่าสุดในโพสต์นั้น (ให้ AI ตอบต่อได้ตรงบริบท) |
| `{{rooms}}` | รายชื่อห้อง TinyForum ที่ให้ AI เลือก |
| `{{room}}` `{{title}}` `{{body}}` | ห้อง / หัวข้อ / เนื้อหา ของกระทู้ที่กำลังโหลดคอมเมนต์ |
| `{{batch}}` | จำนวนคอมเมนต์ต่อการโหลด 1 ครั้ง |
| `{{existing}}` | คอมเมนต์+รีพลายที่มีอยู่แล้วในกระทู้ (มีเลขกำกับ กันซ้ำ + ให้ตอบกลับได้) |

> แต่ละเทมเพลตหน้าตั้งค่าจะบอกไว้ว่าใช้ marker อะไร และมี token ไหนใช้ได้บ้าง

## 💾 การเก็บข้อมูล

- **ผูกกับแชทแต่ละอัน** (`chat_metadata.tinyfeed`) — ฟีด · ข่าว · NPC · แชต/กลุ่ม TinyConnect · ไลฟ์ TinyStream · **กำหนดการ+โน้ต TinyMemo** · **กระทู้ TinyForum** · หน้าจอล่าสุด → สลับแชทไม่ปนกัน ไม่หายเมื่อรีเฟรช
- **ตั้งค่าส่วนกลาง** (`extension_settings.tinyfeed`) — ธีม/สี/วิดเจ็ต/Custom CSS · การแจ้งเตือน + ทักเชิงรุก · ห้อง TinyForum · **prompt ที่แก้เอง** · ประวัติแจ้งเตือน · config ทุกแอป

## 📥 การติดตั้ง

1. **Extensions → Install Extension** วาง GitHub URL → Refresh (Ctrl+F5)
2. กดไอคอนไม้กายสิทธิ์ → เลือก **TinyFeed**

หรือวางไฟล์เองที่ `SillyTavern/public/scripts/extensions/third-party/tinyfeed/`

> ⚠️ ชื่อโฟลเดอร์ต้องเป็น `tinyfeed` เท่านั้น · แจ้งเตือน OS ต้องเปิด ST ผ่าน HTTPS/localhost

**ต้องมี:** SillyTavern ที่มี `getContext()` พร้อม `generateQuietPrompt`, `setExtensionPrompt` · (ไม่บังคับ) Connection Manager สำหรับโมเดลแยก

## 🛠️ หมายเหตุสำหรับการพัฒนาต่อ

- ตัวแปรธีม `--tf-*` บน `#tinyfeed-phone` (dark/light) · `.tinyfeed-hidden` = `display:none !important` **โดยตั้งใจ**
- **เพิ่มแอปใหม่:** ไอคอนโฮม (`.tinyfeed-app-icon[data-app]`) + view `.tinyfeed-app` + เคสใน `openApp()` + reset/render ใน CHAT_CHANGED · แท็บของแอปต้องใช้ **คลาสเฉพาะ** (เช่น `.tinyfeed-memo-tabs`) ไม่ใช้ `.tinyfeed-tabs` (กัน settings ซ่อนโดน)
- **เพิ่มหมวดตั้งค่า:** `.tinyfeed-settings-group` + ใส่ชื่อลง `SETTINGS_LAYOUT`
- **เพิ่ม prompt ที่แก้ได้:** เพิ่มใน `PROMPT_DEFS` (label/marker/tokens/default) แล้วให้ generator เรียก `buildPrompt(id, vars)`
- **แจ้งเตือน:** ทุกช่องทางผ่าน `showNotif(...)` → banner + `notifLog` (ลิ้นชัก) + `fireOsNotif` (SW)
