# TinyFeed — TinyPhone 📱

โทรศัพท์จำลองสำหรับโรลเพลย์ใน **SillyTavern** — มีหน้าโฮมและแอปในตัว **11 แอป** ให้ตัวละคร/NPC มีชีวิตนอกบทสนทนาหลัก เสริมบรรยากาศ worldbuilding และ (ถ้าเปิด) ทักหาเราเองได้แม้ไม่ได้เปิดแอปอยู่

> เปิดจากเมนู extensions (ไอคอนไม้กายสิทธิ์ข้างกล่องพิมพ์) → เข้าหน้าโฮม → เลือกแอป

---

## 📲 แอปในเครื่อง

### 📱 TinyFeed — ฟีดโซเชียล + ข่าวสาร
- โพสต์เอง หรือกดให้ AI โพสต์ในนามตัวละครหลัก/NPC (เลือกผู้โพสต์โดยกดรูปโปรไฟล์ในแถบเขียน) · ไลค์ · แชร์ · คอมเมนต์ · หน้ารายละเอียดโพสต์
- **ปุ่ม "ให้ NPC คอมเมนต์"** · **ลบคอมเมนต์** · **AI ตอบคอมเมนต์** (ตอบทันที / กดปุ่มขอ) · **คอมเมนต์ NPC ติดโพสต์ใหม่** (ไม่มี / AI เลือกจำนวน / กำหนดเอง)
- **สร้างโพสต์อัตโนมัติ** ทุก N ข้อความ / ให้ AI ตัดสินใจ / **เมื่อเจอคีย์เวิร์ด** · **แท็บข่าวสาร** AI แต่งข่าวเสริมโลก
- **ส่งสติกเกอร์/รูปจาก TinyGallery** ในโพสต์+คอมเมนต์ได้ (โทเคน `[sticker:]`/`[img:]`) · **เพ็ทก็โพสต์ลงฟีดเองได้** (จาก TinyPet)
- **รีโพสต์ + โควท** — กดปุ่มแชร์บนโพสต์เลือกได้ 3 ทาง: ส่งเข้าแชท TinyConnect / รีโพสต์ทันที / โควทแล้วเขียนข้อความประกอบก่อนโพสต์ · โพสต์ต้นฉบับฝังเป็นการ์ดเล็กในโพสต์ใหม่ (ลบต้นฉบับแล้วการ์ดที่ฝังไว้ยังอยู่ครบ) · โควทโพสต์ที่เป็นโควทอยู่แล้ว ซ้อนได้แค่ 1 ชั้นเสมอ

### 💬 TinyConnect — แชตสไตล์ไลน์
- แชตเดี่ยวกับตัวละครหลัก/NPC · **แชตกลุ่ม** (ตั้งชื่อ + สมาชิก + ตั้งรูปกลุ่มได้) · **แชตกับเพ็ท** (เพ็ททักเราเองตอนหิว/เหงา)
- **แถบพิมพ์สไตล์ไลน์:** `(+เมนูเสริม) (รูป) (ช่องพิมพ์+สติกเกอร์ในช่อง) (ส่ง)` สีตามธีม accent ที่ตั้งไว้ · ปุ่มส่ง**มอร์ฟ**อัตโนมัติ: ช่องว่าง = ไม้กายสิทธิ์ (กดให้ AI ตอบกลับเอง/กลุ่มคุยกันเอง) · พิมพ์ข้อความแล้ว = จรวด (ส่ง)
- ปุ่ม **(+)** = เมนูฟังก์ชันเสริม: **โอนเงิน (สลิป)** · **ส่งของขวัญ** (จาก TinyBag) · **ตั้งพื้นหลังห้องแชต** (เฉพาะห้องนั้น มีฝ้าคลุมสม่ำเสมอทั้งหน้าจอ ไม่เลื่อนหายตอนสกรอลล์)
- **สติกเกอร์/รูปแยกบับเบิลเสมอ** (แม้อยู่กลางข้อความ) · แยกหลายบรรทัดเป็นหลายบับเบิล (เปิด/ปิดได้) · ลบบับเบิลได้
- **โอนเงิน (สลิป)** ระหว่างเรา↔คู่แชท (หัก/เข้า TinyBank) · **กลุ่มคุยกันเอง** · **คู่แชททักหาเราเองอัตโนมัติ** (ทุก N ข้อความ / AI / คีย์เวิร์ด)
- **ของขวัญจาก AI** — เปิดสวิตช์แล้วตัวละครหยิบสินค้าจากแคตตาล็อก TinyShop ซื้อ-ส่งมาให้เราในแชทได้เอง (ตัวละครจ่ายเอง ไม่หักเงินเรา) การ์ดของขวัญที่ได้เก็บเข้า TinyBag ให้ทันที
- **อ่านแล้ว** — เปิดได้ทั้งแบบสุ่มโอกาส (%) และให้ AI เลือกเองว่าจะอ่านเฉยๆ หรืออ่านแล้วตอบด้วย ขึ้นป้าย "อ่านแล้ว · เวลา" ใต้ข้อความล่าสุดของเรา (เฉพาะแชตเดี่ยว ไม่ใช่กลุ่ม/เพ็ท)

### 🎥 TinyStream — ไลฟ์สตรีม + คอมเมนต์สด
- เริ่ม/จบไลฟ์ (AI ตั้งหัวข้อ + สุ่มผู้ชม) · **เลือกสตรีมเมอร์ในหน้าแอป** (ตัวละครหลัก/NPC/เราเอง) · **ไลฟ์หลายคน** (co-host — แตะรูปให้พูด/วนคิว) · **ลบไลฟ์เก่า** ได้
- คอมเมนต์สดผู้ชม AI 3 โหมด (กดโหลด / อัตโนมัติ / ตอนเราคอมเมนต์) · พิมพ์คอมเมนต์เองได้ · **สตรีมเมอร์หลายคนพูดได้ในเจนเดียว**
- **โดเนท SuperChat** — AI ให้ผู้ชมโดเนท (เข้า TinyBank ถ้าเราเป็นคนไลฟ์) · **เราโดเนทให้สตรีมเมอร์คนอื่นได้** (ไอคอนในแถบคอมเมนต์)

### 📅 TinyMemo — กำหนดการ + โน้ต/ความจำ
- **แท็บกำหนดการ** — ไทม์ไลน์อีเวนต์ที่กำลังจะเกิด · ติ๊กเสร็จ / AI ขีดฆ่าอันที่ผ่านไป · **แท็บโน้ต/ความจำ** — บันทึกเหตุการณ์/ข้อเท็จจริงที่อยากให้จำ
- ปุ่ม **"สแกน"** ครั้งเดียวได้ทั้งสองแท็บ (auto/keyword ได้) · เพิ่มเอง/ลบได้ · ใช้เป็น **แหล่งความจำให้ตัวละคร RP** ได้

### 🗣️ TinyForum — เว็บบอร์ด/กระทู้
- ตั้งกระทู้เอง หรือ "ให้ชาวเน็ตตั้งกระทู้" (AI สร้างจากเนื้อเรื่อง) · แท็บ **ล่าสุด / มาแรง** · คอมเมนต์เยอะ + **ตอบกลับซ้อน 1 ชั้น** + **โหลดคอมเมนต์เพิ่ม**
- ไลค์/ลบ ได้ · **ระบบห้อง/หมวด** เพิ่ม-แก้เองในตั้งค่า (AI เลือกจากรายการ) · auto/keyword ได้

### 🖼️ TinyGallery — คลังรูป + สติกเกอร์ + จัดการไฟล์ *(global)*
- เก็บ **รูป + สติกเกอร์** เป็นอัลบั้ม (ข้ามแชท) · ส่งด้วยโทเคน `[img:ชื่อ]` / `[sticker:ชื่อ]` — แสดงผลอัตโนมัติในทุกแอป (feed/connect/stream/forum)
- **รูป > สติกเกอร์** — ถ้าส่งพร้อมกัน แสดงแค่รูป · ตั้งได้ว่าให้ AI เข้าถึงอัลบั้มไหน (ส่งสติกเกอร์/รูปเองได้)
- **📤 อัปโหลดรูปจากเครื่องได้** (ไม่ต้องหา image host) — ปุ่มอัปโหลดอยู่ทุกที่ที่รับลิงก์รูป: คลังรูป/สติกเกอร์ · รูปโปรไฟล์ผู้ใช้/ตัวละคร/NPC · รูปกลุ่ม TinyConnect · วอลเปเปอร์ · พื้นหลังเวที TinyStream · พื้นหลังห้องแชต TinyConnect · สไปรต์ TinyPet · สินค้า TinyShop/ร้านเพ็ท — ไฟล์ถูกย่อ/บีบอัตโนมัติก่อนอัปโหลดขึ้นเซิร์ฟเวอร์ ST (ไม่กินพื้นที่ settings.json)
- **แท็บ "ไฟล์ทั้งหมด"** — ลิสต์ไฟล์ที่อัปโหลดขึ้นเซิร์ฟเวอร์ ST จริง พร้อมบอกว่าไฟล์ไหน "ใช้อยู่ N ที่" หรือ "ไม่พบการอ้างอิง" (ตรวจได้เฉพาะแชทที่เปิดอยู่ตอนนี้) · ลบทีละไฟล์ หรือลบไฟล์ที่ไม่พบการอ้างอิงทั้งหมดในคลิกเดียว — **ลบถาวรจากดิสก์ กู้คืนไม่ได้**

### 💰 TinyBank — ธนาคาร/การเงิน *(ผูกกับแชท)*
- ยอดเงิน + ประวัติธุรกรรม (แยกตามเนื้อเรื่อง) · เพิ่ม/จ่ายเงินเอง · เป็นแหล่งเงินกลางให้ทุกแอป (สลิป TinyConnect · โดเนท TinyStream · ซื้อของ TinyShop · เติมเหรียญ TinyPet)
- **สัญลักษณ์สกุลเงินผูกกับการ์ดตัวละคร** (ไม่ใช่ทั้งเรื่อง) — การ์ดแฟนตาซีตั้ง "โกลด์" การ์ดยุคใหม่ตั้ง "฿" ได้พร้อมกัน ตั้งได้ยาวเท่าไหร่ก็ได้ ไม่มีตัวละคร = ใช้ค่าเริ่มต้นไปก่อน
- **สแกนเงินจากบท RP** — กดปุ่มสแกน (หรือให้ AI สแกนอัตโนมัติเป็นระยะ) ให้ AI อ่านบทล่าสุดแล้วหาเหตุการณ์เกี่ยวกับเงินที่เกิดขึ้นจริง (ได้ค่าจ้าง/รางวัล/จ่ายของ ฯลฯ) ผลลัพธ์เข้าคิว **รอตรวจสอบก่อนเสมอ** — กดยอมรับ/ปฏิเสธทีละรายการ ไม่ตัดเงินอัตโนมัติทันที (กัน AI หลอนแต่งเหตุการณ์เงินที่ไม่ได้เกิดขึ้นจริง)

### 🛍️ TinyShop — ร้านค้า *(ผูกกับแชท)*
- เพิ่มสินค้าเอง (ชื่อ/ราคา/**รูปหรืออิโมจิ**/หมวด/รายละเอียด) หรือ **"ให้ AI สร้างสินค้า"** เข้ากับโลกของเรื่อง · **ปุ่มแก้ไข** ต่อสินค้า
- **แคตตาล็อกสินค้าแยกตามแชท** (แต่ละเรื่องมีร้านของตัวเอง) · **หมวดหมู่ใช้ร่วมทุกแชท** เพิ่ม-ลบเองในตั้งค่า + แถบกรองหมวด · ซื้อด้วยเงิน TinyBank — ของที่ซื้อไปเก็บเข้า **TinyBag**

### 🐾 TinyPet — สัตว์เลี้ยงเสมือน (ทามาก็อตจิ) *(global)*
- เลี้ยงสัตว์ 1 ตัว **ตัวเดียวกันทุกแชท** · ค่า **อิ่ม/พลังงาน/สะอาด/อารมณ์/สุขภาพ** ลดตาม **เวลาจริง** แม้ปิด ST (มีเพดานกันหายนานแล้วตายทันที + ตั้ง **หยุดค่าลดเมื่อไม่มีคนใช้เกิน N นาที** ได้)
- **ให้อาหาร/เล่น/อาบน้ำ/นอน** (cooldown + ให้เยอะไปมีผลเสีย) · **sprite ตามสถานะ** (ใส่ลิงก์/วางไฟล์เอง `assets/pet-sprites/<สถานะ>.png` · ไม่มี = อิโมจิ)
- **ความผูกพัน (bonding)** เพิ่มจากการดูแล + **เอ่ยชื่อเพ็ทในบทบาท RP** → ยิ่งผูกพันเพ็ทยิ่งอารมณ์ดีคงทน
- **วิวัฒนาการ (evolution)** — โตตามความผูกพัน: **เด็ก → วัยรุ่น (bond Lv.3) → โตเต็มวัย (bond Lv.6)** · ตอนโตมีแจ้งเตือน + เพ็ททักมาฉลอง · ใส่ sprite ต่อระยะได้ (`<ระยะ>_<สถานะ>.png` เช่น `teen_idle.png` · ว่างไว้ = ใช้ร่างเด็ก)
- **ร้านสัตว์เลี้ยง** แยกต่างหาก — ใช้ **"เหรียญเพ็ท"** (เติมจาก TinyBank / รับจากมินิเกม) ซื้ออาหาร/ของเล่น/ของใช้ (มี effect ต่างกัน) · AI สร้างไอเทม/แก้ไขได้
- **มินิเกม** — จับคู่การ์ด · หา emoji ที่ต่าง (แตะตัวที่ต่าง กริดโตขึ้นเรื่อยๆ, จับเวลา 40 วิ) · ตีตัวตุ่น (ตี 🐹 เลี่ยง 💣, จับเวลา 35 วิ) — เล่นแล้วได้เหรียญ+อารมณ์+ผูกพัน, ใช้พลังงาน
- **AI แต่งบทพูดเพ็ท** ตามสถานะ + คำสั่งเสริม (นิสัย/สายพันธุ์) · เพ็ท **โพสต์ลงฟีด / ทักในแชท** เองได้
- **ให้ตัวละครช่วยดูแลเพ็ทได้** — กดปุ่มแชร์สถานะเพ็ทเข้าแชท TinyConnect แล้วตัวละครสั่งให้อาหาร/เล่น/อาบน้ำเพ็ทกลับมาได้เอง (มีคูลดาวน์กันสแปม ไม่แย่งคูลดาวน์ปุ่มของเรา)
- **โหมดไม่ตาย** (ตั้งได้) — ป่วยหนักสุดได้แต่ไม่ตาย · ปิดโหมดนี้แล้วตายจริง → มีปุ่ม **"ชุบชีวิตให้ฟื้น"** หรือรับเลี้ยงตัวใหม่ก็ได้

### 🙋 TinyAsk — กล่องคำถามนิรนาม
- **แท็บกล่องคำถาม** — คำถามนิรนามที่คนในโลกของเรื่องส่งเข้ามาหาเรา (สุ่มให้เอง หรือกดปุ่ม "ให้คนส่งคำถามเข้ามา") พิมพ์คำตอบแล้วกด "ตอบ" เพื่อเผยแพร่
- **แท็บถาม-ตอบ** — รวมคำถามที่ตอบแล้วทั้งหมด (สไตล์ CuriousCat/Retrospring) ไลค์ได้ · **เฉลยตัวตนผู้ถาม** ได้ถ้าเปิดไว้ในตั้งค่า
- **ส่งคำถามนิรนามหาตัวละคร/NPC เอง** (กด +) เลือกได้ว่าจะไม่ระบุตัวตนหรือไม่ · **ให้ AI ช่วยตอบแทนตัวละคร** หรือ **ให้ AI สุ่มทั้งคำถาม-คำตอบมาเลย** หรือ **ให้ AI ร่างคำถามให้เราแก้ก่อนส่งเอง**
- สร้าง/ตอบอัตโนมัติได้ (ทุก N ข้อความ / AI ตัดสินใจ / คีย์เวิร์ด)

### 🎒 TinyBag — กระเป๋าของ *(ผูกกับแชท)*
- เก็บของที่ **ซื้อจาก TinyShop** หรือ**ได้รับเป็นของขวัญ**จากตัวละครใน TinyConnect ไว้ในที่เดียว (นับจำนวนต่อชิ้น)
- **ใช้** (ลดจำนวนลง 1) · **ทิ้ง** · **ส่งเป็นของขวัญ** ให้คู่แชทใน TinyConnect ได้ (เลือกคนรับจากลิสต์)
- เก็บเป็นสแนปช็อตตอนได้มา — ถึงลบ/แก้สินค้านั้นออกจากแคตตาล็อก TinyShop ไปแล้ว ของในกระเป๋ายังอยู่ครบ

## 📢 ทักเชิงรุก + แจ้งเตือน *(ใหม่)*

### ตัวละครทักหาเราเอง (Proactive)
ตัวจับเวลาเบื้องหลังจะให้ตัวละครหลัก/NPC (สุ่มจากแชท ST ปัจจุบัน) **ทักเข้าห้องแชต TinyConnect เอง** เป็นระยะ — คุมด้วย:
- เว้นระยะขั้นต่ำ (นาที) + โอกาสต่อรอบ (%) + **ช่วงเงียบ (quiet hours)** ไม่ทัก
- สไตล์เสริม (ผสมได้): **ทักตอนเงียบนาน (idle)** · **ตามช่วงเวลาจริง** (เช้า/บ่าย/ดึก) · **ทักผ่านโพสต์ฟีดแทน DM**
- **กลุ่มคุยกันเองอัตโนมัติ** เป็นระยะ

> ⚠️ ทำงานเฉพาะตอน **เปิดแท็บ SillyTavern ค้างไว้** (ย่อ/พับได้ แต่ห้ามปิดแท็บ/เครื่อง sleep) และมีแชตที่มีตัวละครเปิดอยู่ · ไม่ต้องเปิดห้องแชตของใครค้างไว้ ระบบสุ่มเลือกให้เอง · ยิง AI เป็นระยะ = เปลือง token

### แจ้งเตือน 3 ชั้น
- **แบนเนอร์** เลื่อนลงบนจอ (กดแล้วเข้าห้อง/แอปที่เกี่ยว) + จุดแดงนับเลขบนปุ่มเมนู + สั่น
- **ลิ้นชักในโทรศัพท์** — ไอคอน 🔔 บน topbar เก็บประวัติ 30 รายการล่าสุด (แตะเข้าแอป, ล้างได้) · เก็บถาวรข้าม reload
- **แจ้งเตือน OS/desktop จริง** (เปิด/ปิดได้, default ปิด) — ยิงผ่าน Service Worker รองรับมือถือ · มีปุ่ม **"ทดสอบแจ้งเตือน OS"** บอกสาเหตุถ้าติด
  - ต้องเปิด ST ผ่าน **HTTPS หรือ http://localhost** (เปิดผ่าน IP/HTTP ธรรมดา เบราว์เซอร์จะบล็อก)
  - ⚠️ ข้อความจะโผล่บน lock screen/แถบ OS แบบเห็นได้ — **ระวังเนื้อหา 18+**

### จำหน้าจอล่าสุด
เปิดแอปใหม่/หลัง reload จะกลับไปหน้า/ห้องเดิม (ไม่เด้งกลับโฮมทุกครั้ง) · **ปรับหน้าโฮม** เอง — เลือกซ่อน/จัดลำดับไอคอนแอปบนหน้าโฮมได้จากหน้าตั้งค่า

## 🔗 การเชื่อมกับโรลเพลย์

- **แทรกเข้าประวัติแชทหลัก** (`setExtensionPrompt` ตำแหน่ง IN_CHAT, ตั้ง depth ได้) — เลือกได้ 5 แบบ: ไม่แทรก / เฉพาะโพสต์ / เฉพาะข่าว / โพสต์+คอมเมนต์ / โพสต์+คอมเมนต์+ข่าว · เพิ่ม checkbox **แทรกแชต TinyConnect / ไลฟ์ TinyStream / กำหนดการ+โน้ต TinyMemo / กระทู้ TinyForum / ธุรกรรม TinyBank / สินค้า TinyShop / ของในกระเป๋า TinyBag / สถานะ TinyPet / คำถาม TinyAsk** → ตัวละครอ้างอิงได้ เช่น *"เห็นที่โพสต์แล้วนะ" / "อย่าลืมนัดพรุ่งนี้"*
- **เชื่อมเนื้อหาข้ามแอป** — เป็น **checkbox รายแหล่ง** ต่อทั้ง 11 แอป/แหล่งข้างบน เลือกได้ว่าให้แอปอื่นเห็นอะไรบ้าง · แชต TinyConnect ปิดไว้ default เพื่อความเป็นส่วนตัว
- **จุดที่ต้องเปิดคู่กันเสมอ** — ฟีเจอร์ที่ให้ AI "หยิบของจริง" มาใช้ (เช่น AI ส่งของขวัญจาก TinyShop, AI ช่วยดูแล TinyPet) ต้องเปิด**ทั้ง**สวิตช์ของฟีเจอร์นั้น**และ**การเชื่อมเนื้อหาข้ามแอปของแหล่งที่เกี่ยวข้อง (shop/pet) ไม่งั้น AI จะมองไม่เห็นแคตตาล็อก/สถานะจริง แล้วเดาไม่ตรง ฟีเจอร์จะดูเหมือนพังทั้งที่ไม่มี error ให้เห็น
- **จำนวนล่าสุดที่แทรก** = นับ "ต่อแอป" (กี่โพสต์/ข่าว/ข้อความต่อคน/คอมเมนต์) · **depth** = ตำแหน่งความลึกในประวัติแชท ไม่ใช่จำนวน

## 🧩 การตั้งค่าขั้นสูง — แก้ Prompt เอง *(ใหม่)*

เผื่อ AI ไม่ทำตามรูปแบบ (เช่นได้คำบรรยายแทนโพสต์) แก้ prompt ของตัวสร้างเนื้อหาได้เอง — ครอบคลุมทั้ง 18 จุดที่มีการเจน AI ในโทรศัพท์: โพสต์ฟีด · คอมเมนต์ติดโพสต์ใหม่ · AI ตอบคอมเมนต์ · ข่าว · ตั้งกระทู้ · คอมเมนต์กระทู้ · คอมเมนต์ผู้ชมไลฟ์ · สตรีมเมอร์พูด/ตอบ · บทพูดเพ็ท · โพสต์ของเพ็ท · สร้างสินค้า TinyShop · สร้างไอเทมร้านเพ็ท · คำถามนิรนามที่ส่งเข้ามา · ตัวละครตอบคำถามนิรนาม · สุ่มคำถาม-คำตอบทั้งคู่ · ร่างคำถามให้ (ทั้งสามอันเป็นของ TinyAsk) · สแกนเงินจากบท RP · ตอบแชต 1:1 (TinyConnect)

**กติกา:**
- ต้องคง **marker** ที่ระบุไว้เสมอ (เช่น `POST:` / `COMMENT:` / `TITLE:` — บางเทมเพลตอย่างสตรีมเมอร์พูด/ตอบแชต 1:1 ไม่มี marker เพราะเอาคำตอบทั้งก้อนไปใช้ตรงๆ) — เพราะระบบใช้ marker นี้แยกผลลัพธ์ · ถ้าลบออก → ขอบแดง + ไม่บันทึก
- กด **"คืนค่าเริ่มต้น"** เพื่อรีเซ็ตเทมเพลตนั้น
- `{{...}}` = ช่องที่ระบบเติมข้อมูลให้อัตโนมัติตอนสร้าง (อย่าพิมพ์ทับ ให้วางไว้ในตำแหน่งที่ต้องการ)

### {{ }} แต่ละอันแทนอะไร

| Token | แทนที่ด้วย |
|---|---|
| `{{roster}}` | รายชื่อผู้โพสต์/คอมเมนต์ที่ให้ AI เลือก (ตัวละครหลัก + NPC ประจำ) |
| `{{extra}}` | คำสั่งเสริมที่ผู้ใช้พิมพ์ในช่อง "คำสั่งเสริม" ของแอปนั้น |
| `{{history}}` | โพสต์/หัวข้อข่าวล่าสุดที่มีอยู่แล้ว (กันเขียนซ้ำ) |
| `{{context}}` | เนื้อหาจากแอปอื่น (เมื่อเปิด "เชื่อมเนื้อหาข้ามแอป") |
| `{{postText}}` | ข้อความของโพสต์ที่กำลังคอมเมนต์ |
| `{{author}}` | ชื่อเจ้าของโพสต์ |
| `{{count}}` | คำสั่งจำนวนคอมเมนต์/คำถามที่ให้เขียน (ตามโหมดของแอปนั้น) |
| `{{thread}}` | คอมเมนต์ล่าสุดในโพสต์นั้น (ให้ AI ตอบต่อได้ตรงบริบท) |
| `{{rooms}}` / `{{room}}` | รายชื่อห้อง TinyForum ให้เลือก / ห้องของกระทู้ที่กำลังคอมเมนต์ |
| `{{title}}` `{{body}}` | หัวข้อ / เนื้อหา ของกระทู้ (TinyForum) หรือไลฟ์ (TinyStream) ที่กำลังใช้งาน |
| `{{batch}}` | จำนวนคอมเมนต์ต่อการโหลด 1 ครั้ง (TinyForum) |
| `{{existing}}` | คอมเมนต์+รีพลายที่มีอยู่แล้วในกระทู้ (TinyForum) หรือรายการเหตุการณ์เงินที่บันทึกแล้ว (TinyBank — กันสแกนซ้ำ) |
| `{{streamer}}` `{{direction}}` | ชื่อสตรีมเมอร์ / ทิศทาง-หัวข้อไลฟ์ที่กำลังดำเนิน (TinyStream) |
| `{{task}}` `{{transcript}}` | งานที่ให้สตรีมเมอร์ทำตอนนี้ / บทพูดล่าสุดในไลฟ์ (สตรีมเมอร์พูด) หรือบทแชตล่าสุด (ตอบแชต 1:1) |
| `{{recent}}` | คอมเมนต์/เหตุการณ์ล่าสุดที่เพิ่งเกิด (TinyStream คอมเมนต์ผู้ชม, TinyBank สแกนเงิน) |
| `{{petName}}` `{{stage}}` `{{stats}}` `{{lastAction}}` `{{mood}}` `{{types}}` | ชื่อ/ระยะวิวัฒนาการ/ค่าสถานะ/การกระทำล่าสุด/อารมณ์เพ็ท และประเภทไอเทมที่เลือกได้ (TinyPet) |
| `{{cats}}` | หมวดสินค้าที่เลือกได้ (TinyShop) |
| `{{owner}}` `{{question}}` | เจ้าของกล่องคำถามที่กำลังถูกถาม/ตอบ · เนื้อคำถามที่ต้องตอบ (TinyAsk) |
| `{{you}}` `{{name}}` `{{markers}}` `{{gallery}}` | ชื่อเรา / ชื่อคู่แชท / คำสั่งมาร์คเกอร์พิเศษที่เปิดใช้ (สลิป/ของขวัญ/ดูแลเพ็ท/อ่านแล้ว) / รายการสติกเกอร์ที่ส่งได้ (ตอบแชต 1:1 TinyConnect) |

> แต่ละเทมเพลตหน้าตั้งค่าจะบอกไว้ว่าใช้ marker อะไร และมี token ไหนใช้ได้บ้าง

## 🛠️ หมายเหตุสำหรับการพัฒนาต่อ

- ตัวแปรธีม `--tf-*` บน `#tinyfeed-phone` (dark/light) · `.tinyfeed-hidden` = `display:none !important` **โดยตั้งใจ**
- **เพิ่มแอปใหม่:** เพิ่ม entry ใน `APPS` (id/name/icon/สี/panel/`open()`/`back()`) — หน้าโฮมอ่านรายการจาก `homeAppList()` เท่านั้น (เคารพลำดับ/ซ่อนที่ผู้ใช้ตั้งไว้) ไม่มี array แยกสำหรับหน้าโฮมอีกแล้ว · เพิ่ม panel `.tinyfeed-app` ใน `phone.html` · แท็บของแอปต้องใช้ **คลาสเฉพาะ** (เช่น `.tinyfeed-memo-tabs`) ไม่ใช้ `.tinyfeed-tabs` (กัน settings ซ่อนโดน)
- **เพิ่มหมวดตั้งค่า:** `.tinyfeed-settings-group` + ใส่ชื่อลง `SETTINGS_LAYOUT`
- **เพิ่ม prompt ที่แก้ได้:** เพิ่มใน `PROMPT_DEFS` (label/marker/tokens/default) แล้วให้ generator เรียก `buildPrompt(id, vars)`
- **เพิ่มแหล่งที่แทรกเข้า RP / เชื่อมข้ามแอปได้:** เพิ่ม entry เดียวใน `INJECT_SOURCES` (ไม่ต้องแก้หลายที่)
- **เพิ่มมาร์คเกอร์ที่ AI สั่งกลับมาในแชต 1:1 TinyConnect** (เช่น สลิป/ของขวัญ/ดูแลเพ็ท/อ่านแล้ว): เพิ่ม entry ใน `CONNECT_MARKERS` (setting เปิด-ปิด/regex จับ/บรรทัดสอน prompt/ตัวจัดการผลลัพธ์)
- **แจ้งเตือน:** ทุกช่องทางผ่าน `showNotif(...)` → banner + `notifLog` (ลิ้นชัก) + `fireOsNotif` (SW)
