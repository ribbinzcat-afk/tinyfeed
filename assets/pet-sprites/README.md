# TinyPet sprites

วางไฟล์รูป sprite ของสัตว์เลี้ยงไว้ในโฟลเดอร์นี้ ตั้งชื่อไฟล์ตามสถานะ (ใช้ `.png` พื้นหลังโปร่งใส แนะนำ ~128×128px):

| ไฟล์ | สถานะ |
|------|-------|
| `idle.png` | ปกติ (อยู่เฉยๆ) |
| `happy.png` | อารมณ์ดี |
| `hungry.png` | หิว |
| `sleepy.png` | ง่วง |
| `dirty.png` | ตัวเลอะ |
| `sick.png` | ป่วย (สุขภาพต่ำ) |
| `eating.png` | กำลังกินอาหาร (โชว์ตอนกดให้อาหาร) |
| `playing.png` | กำลังเล่น |
| `cleaning.png` | กำลังอาบน้ำ |
| `sleeping.png` | กำลังหลับ |
| `dead.png` | เสียชีวิต |

- **ไม่ต้องมีครบทุกไฟล์** — สถานะไหนไม่มีไฟล์ (และไม่ได้ใส่ลิงก์ในหน้า Settings) จะ fallback เป็นอิโมจิให้อัตโนมัติ
- **ใส่ลิงก์แทนไฟล์ก็ได้** — หน้า Settings › TinyPet มีช่องกรอกลิงก์รูป (รองรับ PNG/GIF/รูปเคลื่อนไหว) ต่อสถานะ ลิงก์จะทับไฟล์ในโฟลเดอร์นี้
- **Evolution ในอนาคต:** ถ้าเพิ่มระยะ baby/teen/adult ให้ตั้งชื่อ prefix เช่น `baby_idle.png`, `teen_idle.png` (โค้ดยังไม่ใช้ prefix ใน MVP)
