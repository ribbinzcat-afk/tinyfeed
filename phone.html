TinyStream (ไลฟ์สตรีม)
เลือกสตรีมเมอร์หลัก + ตัวละครร่วมไลฟ์ได้ที่หน้าแอป TinyStream (กดที่รูปโปรไฟล์ในกรอบสตรีม · ปุ่ม + เพื่อเพิ่มตัวละครร่วม) โหมดอัตโนมัติจะเรียก AI เรื่อยๆ ตอนเปิดหน้าไลฟ์ (เปลือง token) · ตั้งวินาทีสูงขึ้นเพื่อประหยัด ตอนเริ่มไลฟ์ตั้งหัวข้อ + แนวทางเองได้ (เว้นว่าง = ให้ AI ตั้ง) · สตรีมเมอร์จะทักเปิดไลฟ์เอง + มีปุ่ม "ให้สตรีมเมอร์พูด" ในหน้าไลฟ์ · มอโนล็อกทำงานตามรอบเวลาเดียวกับคอมเมนต์อัตโนมัติ
TinyConnect (แชต)
คู่แชท (คนใดคนหนึ่งใน TinyConnect) จะส่งข้อความมาหาเราเองตามจังหวะเนื้อเรื่อง มีแจ้งเตือนเหมือนได้ไลน์ · ต่างจาก "ทักเชิงรุก" ในหน้าทั่วไปที่ทักตามเวลาจริง — อันนี้ทักตามจำนวนข้อความ RP/คีย์เวิร์ด · คีย์เวิร์ดตั้งในกลุ่ม "ทริกเกอร์ด้วยคีย์เวิร์ด" เราโอนออกเองได้เสมอจากปุ่ม 💸 ในแชท (หักจาก TinyBank) · เปิดตัวเลือกนี้ = ตอนกด "ให้ตอบกลับ" คู่แชทอาจโอนเงินเข้าบัญชีเรา (ตามเนื้อเรื่อง) เข้า TinyBank อัตโนมัติ
โมเดล / API
ข้อมูลการ์ดตัวละคร + persona ส่งเต็มเสมอ · World Info ถ้ายาวมากค่อยตั้งลิมิตกัน prompt บวม แยกโมเดลของ TinyFeed ออกจากโมเดลตอบ RP ได้ · ต้องสร้าง connection profile ใน Connection Manager ของ ST ก่อน · โหมด "API หลัก" ได้ context เนื้อเรื่องอัตโนมัติ ส่วนโมเดลแยกเราจะแนบบทสนทนาล่าสุดให้ตามจำนวนนี้ (มากขึ้น = เข้าใจเนื้อเรื่องดีขึ้น แต่เปลือง token)
วอลเปเปอร์
รูปโปรไฟล์
โปรไฟล์ของคุณ — ผูกกับ persona: —
ผูกกับ persona ปัจจุบัน · เว้นว่าง = ใช้รูป/ชื่อ persona ตามปกติ · ชื่อในเนื้อหาที่ตรงกับ username/alias จะถูกแทนด้วยรูปคุณ
โปรไฟล์ตัวละคร — ผูกกับการ์ด: —
ผูกกับการ์ดตัวละคร · เว้นว่าง = ใช้ชื่อ/รูปการ์ด · แอปจะแสดงตัวละครด้วยชื่อหลักที่เลือก · ชื่อในเนื้อหาที่ตรงกันจะถูกแทนด้วยรูปตัวละคร
โพสต์จากตัวละคร (AI)
โพสต์ที่ AI สร้างจะสุ่มไลค์ในช่วงนี้ · เลขเยอะจะย่อเป็น K/M ในฟีด แต่โชว์เต็มเมื่อกดเข้าโพสต์ แนบโพสต์ล่าสุดเป็นบริบท → AI ไม่โพสต์ซ้ำ + อ้างอิงได้ · 0 = ไม่แนบ (ยิ่งเยอะยิ่งเปลือง token)
NPC ประจำ (ตัวละครนี้)
กำหนดตัวละครประจำโลกของแชทนี้ · AI จะเลือกโพสต์จากรายชื่อนี้ · ใส่ลิงก์รูปให้ NPC มีรูปเฉพาะตัว (เว้นว่าง = วงกลมสีอักษรแรก)
สร้างโพสต์อัตโนมัติ
โหมด "ทุกๆ จำนวนข้อความ" = ครบตามจำนวนแล้วสร้างเลย · "ให้ AI ตัดสินใจเอง" = ครบแล้ว AI เช็คก่อนว่าควรโพสต์ไหม · นับจากตอนเปิดแชท
ข่าวสาร
กดปุ่ม "สร้างข่าวใหม่" ในแท็บข่าวสารสร้างเองได้ · ข่าวปกติควรตั้งจำนวนข้อความสูงกว่าโพสต์ (ข่าวไม่ควรมาถี่) ข่าวถูกตัด/ยาวเกิน = เพิ่ม token · ตั้งค่าน้อยไป = ข่าวสั้น
แทรกฟีดเข้าประวัติแชท
แหล่งที่ให้แอปอื่นมองเห็น
เปิดแล้วตอน AI สร้างเนื้อหาในแอปหนึ่ง จะเห็นเนื้อหา "แหล่งที่ติ๊กไว้" ของแอปอื่น เช่น ผู้ชมไลฟ์พูดถึงข่าว หรือโพสต์อ้างอิงแชต (ใช้ token เพิ่ม) · แอปที่กำลังสร้างจะไม่เอาเนื้อหาตัวเองมาซ้ำ · แชต TinyConnect เป็นเรื่องส่วนตัว จึงปิดไว้เป็นค่าเริ่มต้น แทรกเนื้อหาล่าสุดเข้า context ของ RP หลัก → ตัวละครอ้างอิงได้ (เช่น "เห็นที่โพสต์แล้วนะ") จำนวนล่าสุดที่แทรก = นับ "ต่อแอป" ของจำนวนรายการล่าสุด: โพสต์กี่โพสต์ / ข่าวกี่ข่าว / แชตกี่ข้อความต่อคน / คอมเมนต์สดกี่อัน · และถ้าเปิดโหมดรวมคอมเมนต์ ก็จำกัดคอมเมนต์ต่อโพสต์เท่าจำนวนนี้เช่นกัน (มากขึ้น = เข้าใจบริบทดีขึ้น แต่เปลือง token) depth = แทรกลึกกี่ข้อความจากล่าสุด (ต่ำ = ใกล้ปัจจุบัน) ไม่เกี่ยวกับจำนวน เป็นตำแหน่งที่วางข้อมูลในประวัติแชท
คอมเมนต์
ตอนสร้างโพสต์ใหม่ (ทั้ง AI สร้างและเราโพสต์เอง) จะมีคอมเมนต์ NPC ติดมาตามนี้ · โพสต์เราจะได้ยอดไลค์สุ่มด้วย (ใช้ generation เพิ่ม = เปลือง token ขึ้น)
TinyMemo (กำหนดการ + โน้ต)
สแกนครั้งเดียวได้ทั้ง 2 แท็บ: หา "กำหนดการที่กำลังจะเกิด" มาเรียงไทม์ไลน์ + ขีดฆ่าอันที่ผ่านไปแล้ว และจด "เหตุการณ์สำคัญ/สิ่งที่ควรจำ" ลงโน้ต · โหมด "ให้ AI ตัดสินใจ" จะเช็คก่อนว่ามีอะไรควรจดไหม (ประหยัด token) · เปิด auto แล้วจะมีแจ้งเตือนเมื่อมีรายการใหม่
TinyForum (เว็บบอร์ด)
ห้อง/หมวด (AI เลือกจากรายการนี้)
ตอน AI ตั้งกระทู้จะเลือกห้องจากรายการนี้ · ห้องใช้ร่วมทุกแชท · โหลดคอมเมนต์เพิ่มได้เรื่อยๆ ในหน้ากระทู้ (ยิ่งเยอะยิ่งเปลือง token)
TinyGallery (คลังรูป + สติกเกอร์)
คลังรูป/สติกเกอร์เป็น global ใช้ร่วมทุกแชท ไม่เปลี่ยนตามแชท · เปิดตัวเลือกแรกจะแนบรายชื่อสติกเกอร์/รูป (ตามขอบเขต+จำนวนสูงสุด) เข้าไปตอน AI คุย/โพสต์ เพื่อให้เลือกส่งด้วย [sticker:ชื่อ] / [img:ชื่อ] · ผู้ใช้กดปุ่ม 😊 ในแถบพิมพ์เพื่อส่งเองได้ทุกแอป
TinyBank (ธนาคาร)
สี tier โดเนท (SuperChat — ยอด ≥ ขั้นต่ำ ใช้สีนั้น)
ยอดเงิน + ประวัติธุรกรรมผูกกับแชท (แยกตามเนื้อเรื่อง) · เปิดระบบโดเนท → เวลาโหลดคอมเมนต์สดใน TinyStream, AI จะเลือกให้ผู้ชมโดเนท (กำหนดจำนวน+ข้อความเอง) เข้าบัญชีเรา เด้งการ์ดสีตาม tier บนจอไลฟ์ · ปิดไว้ = เพิ่ม/จ่ายเงินเองเท่านั้น
ทริกเกอร์ด้วยคีย์เวิร์ด
ตั้ง "โหมด" ของแต่ละแอปด้านบนเป็น "เมื่อเจอคีย์เวิร์ด" แล้วแอปนั้นจะสร้างเนื้อหาให้อัตโนมัติเมื่อข้อความ RP ล่าสุดมีคำที่ตรงกับรายการด้านล่าง · ทำงานทันทีในเบราว์เซอร์ ไม่หน่วง ไม่ต้องโหลดโมเดล · คั่นคำด้วยจุลภาค (,) หรือขึ้นบรรทัดใหม่ เลือกว่าจะให้คีย์เวิร์ดจับจากข้อความล่าสุดฝั่งใด — เช่น "เฉพาะผู้ใช้" = ทริกเกอร์เมื่อเราพิมพ์คำนั้น, "เฉพาะตัวละคร" = เมื่อตัวละคร/AIพูดถึง
กันทริกเกอร์ถี่เกินไป — เจอคีย์เวิร์ดแล้วต้องเว้นอย่างน้อยเท่านี้ก่อนจะสร้างซ้ำ (แยกต่อแอป)
TinyShop (ร้านค้า)
หมวดสินค้า (AI เลือกจากรายการนี้)
กด "ให้ AI สร้างสินค้า" ในแอป TinyShop ให้ AI แต่งสินค้าเข้ากับโลกของเรื่อง · หมวดใช้ร่วมทุกแชท · แก้รูป/อิโมจิ/หมวดของสินค้าได้จากปุ่มดินสอบนสินค้า
TinyPet (สัตว์เลี้ยง)
สัตว์เลี้ยงเป็น global (ตัวเดียวกันทุกแชท) · ค่าต่างๆ ลดตามเวลาจริงแม้ปิด ST ไป
อัตราลดต่อนาที (ยิ่งมากยิ่งต้องดูแลถี่)
รูป sprite ต่อสถานะ (ใส่ลิงก์เอง · ว่าง = ใช้ไฟล์ในตัว assets/pet-sprites/)
รองรับลิงก์ PNG/GIF/รูปเคลื่อนไหว · วางไฟล์เองในโฟลเดอร์ assets/pet-sprites/<สถานะ>.png ก็ได้ (ไม่ต้องใส่ลิงก์)
Prompt (ขั้นสูง)
